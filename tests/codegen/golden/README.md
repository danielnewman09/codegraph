# Codegen golden fixtures

These are Codegraph-owned reviewed inputs for `tests/codegen/` snapshot and
round-trip tests. They are updated only alongside an intentional Codegraph
contract change and are never synchronized from another repository.

Generated one-hop and implementation exports live in `tests/unit_test_data/`
as inspection artifacts. Their Codegraph producers and consumers declare the
same local paths; the artifacts are not committed test inputs.
